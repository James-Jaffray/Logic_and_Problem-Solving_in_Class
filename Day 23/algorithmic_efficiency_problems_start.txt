2. The following code will check if a given list is sorted:

            isSorted = false
            BREAK   // exit inner for loop

3. Finding common elements between two arrays

DECLARE list1 = [1, 2, 3, 4, 5]
DECLARE list2 = [3, 4, 5, 6, 7, 8]
DECLARE common = []

FOR i = 0 TO length(list1) - 1
    FOR j = 0 TO length(list2) - 1
        IF list1[i] == list2[j] THEN
            IF list1[i] NOT IN common THEN
                ADD list1[i] TO common
            ENDIF

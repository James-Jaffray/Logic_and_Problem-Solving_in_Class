# Logic and Problem-Solving — Day 7: Decision Structures and Loops in Flowcharts

**Today's focus:** show decisions and repetition in flowcharts using decision diamonds, `while` loops, and `do-while` loops.

## [[Loops]] in Flowcharts
| Structure | Checks condition | Runs at least once? |
|---|---|---|
| Decision (`if`) | Before | No — branches one way or the other |
| `while` loop | Before each pass | No |
| `do-while` loop | After each pass | Yes |

- A loop is a decision diamond whose "repeat" arrow points **back** up to an earlier step (use a new arrow — see [[Flowcharts]])
- Invalid input is a classic loop: ask again until the answer is valid (see [[Conditionals]])

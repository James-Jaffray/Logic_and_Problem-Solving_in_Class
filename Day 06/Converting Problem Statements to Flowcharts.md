# Logic and Problem-Solving — Day 6: Converting Problem Statements to Flowcharts

**Today's focus:** turn an analyzed problem statement into a flowchart, then refine it.

## Conversion Steps
First identify the key parts of the statement: **inputs, process, output, conditions**. Then:
1. Identify the start and end points (terminal symbols)
2. Break the process into clear, sequential steps — one step per symbol
3. Assign the appropriate flowchart symbol to each step
4. Ensure logical flow and completeness

**Example — bookstore loyalty discount** (5% off if total spend > $500):

| Step | Symbol |
|---|---|
| Start program | Oval (terminal) |
| Enter purchase amount | Parallelogram (input) |
| Check if amount > $500 | Diamond (decision) |
| Calculate the discount | Rectangle (process) |
| Print the discount (0 if under $500) | Parallelogram (output) |
| End program | Oval (terminal) |

## [[Flowchart Refinement]]
Complex flowcharts get errors, so review and improve them afterward. Check:
- **Correct shapes** — follow industry standards so non-technical teams can read them
- **Logical consistency** — steps connected in the right order
- **Readability** — split long charts into pieces using connectors
- **Decision points** — every decision has two output paths
- **Efficiency** — remove unnecessary steps ("make it work," then "make it work efficiently")
